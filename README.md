# Jayarakshaa N's Developer Portfolio

A clean, modern, and responsive personal portfolio website built with plain HTML and CSS. It introduces me as a first-year B.Tech student, showcases a few starter projects, and lists ways to get in touch.

## About this project

This site includes:
- A responsive header with a Flexbox-based navigation bar
- An About section with a short bio
- A Projects section with project cards laid out using CSS Grid (1 column on mobile, 3 columns on desktop)
- A Contact footer with Email, GitHub, and LinkedIn links
- A simple, consistent color and typography system using CSS variables

## How to run it locally

1. Download or clone this folder (it should contain `index.html`, `style.css`, and this `README.md`).
2. Open `index.html` directly in any web browser (double-click the file, or right-click → "Open with" → your browser).
3. That's it — no build tools, servers, or installations needed.

### Deploying to GitHub Pages (quick steps)

1. Create a new GitHub repository and push these three files to it.
2. Go to the repository's **Settings → Pages**.
3. Under "Source", select the `main` branch and the `/ (root)` folder, then save.
4. Wait a minute for GitHub to build the site, then visit the URL shown on that page.
